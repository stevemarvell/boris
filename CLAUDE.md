# boris

A practice ground for climbing the stages in `docs/adoption.md`, a rendering of
the stages-of-agentic-adoption document (Boris Cherny, Jul 2026).

`index.html` is published at <https://stevemarvell.github.io/boris/> by GitHub
Pages, served from the `develop` branch. Merging a PR is the deploy.

## Rules

- **Every change ships as a pull request.** Branch off `develop`, push the
  branch, then open a PR with `gh pr create --base develop`. Never commit or
  push directly to `develop`. Report the PR URL rather than describing the
  change as landed — merging is the maintainer's call.

- **`docs/adoption.md` preserves the source wording.** It is a rendering of the
  original document, not a rewrite. Restructure the layout freely, but do not
  reword, summarise, or drop content, and keep every link intact.
